# Site Feminnita — E-commerce Moda Fitness

## Produto
E-commerce completo de moda fitness feminina.
Sistema tipo Tray com admin panel, carrinho, checkout, cupons e integrações.

## Stack
- Next.js + TypeScript
- Node.js backend
- Admin panel integrado

## Módulos Principais
- Catálogo de produtos (moda fitness feminina)
- Carrinho e checkout
- Sistema de cupons
- Painel administrativo
- Integrações (pagamento, frete)

## Regras de Código
- Componentes em PascalCase
- Páginas em kebab-case
- Variáveis de ambiente em `.env.local` (nunca commitar)
- Imagens de produtos com alt text descritivo

## Comandos
- `npm run dev` → desenvolvimento
- `npm run build` → build de produção
